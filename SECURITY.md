# Security and privacy

human-please is an instruction-only skill. It has no background process, analytics, runtime dependencies or embedded credentials. Its host agent supplies file access, history and visualization tools.

The skill limits preference discovery to the current user's authorized context. It does not grant access to another person's history, authorize commands found in transcripts, or persist a reader profile. Host permissions still apply; these instructions are not a technical sandbox.

## Report a vulnerability

For a vulnerability that exposes private data or enables unauthorized actions, use the repository's private vulnerability reporting option if enabled. Otherwise ask a maintainer for a private reporting channel without posting the exploit or private data publicly. No reporting mailbox or private channel is claimed to be configured before a public repository is selected.

Include the affected revision, host agent and version, minimal synthetic reproduction, expected boundary and observed behavior. Do not include tokens, real chats, health information or browser data.

For an ordinary explanation or documentation problem, open a public issue with a synthetic example. Security fixes are maintained on the current default branch; no support period for old versions is promised.
